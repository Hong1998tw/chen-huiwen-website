## 資料口徑

- 原始政績、政見、活動 JSON 未修改；42 筆原始政績中只使用原已公開 20 筆，22 筆待核驗資料不加入索引及統計。
- 初始狀態：持續追蹤 13、爭取規劃 3、已完成 3、政策實施 1。不是 20 件完工工程。
- 里別、主題與年度是多值分類；加總可能超過專題數。
- 年度取歷程明載西元年份；沒有歷程年度的 3 筆獨立列為「未載歷程年度」。未把資料更新日或學年度推算成完工日期。
- 點位只代表位置，不是工程範圍。原始經費與日期沒有修改。

## 驗證

本次版本共 55 頁 HTML、54 筆可索引頁面，含新增服務條款。所有公開頁面有唯一標題、description、canonical、OG／Twitter 與單一 h1；新聞詳情頁含 Article 結構化資料。

執行狀態請查同一 commit 的 GitHub Actions 與其附件，不沿用先前私人預覽的瀏覽器或效能數字。全站回歸涵蓋桌面、390px、頁面溢出、選單鍵盤、搜尋、篩選、地圖、無 JavaScript 與無障礙。手機首頁照片按本版要求放大，並驗證與下方內容左緣對齊。

## 維護

正常內容／版型更新後：

```bash
python3 scripts/build_cases.py
python3 scripts/build_platforms.py
python3 scripts/build_events.py
python3 scripts/build_search.py
python3 scripts/validate_p0.py
```

專題標題、狀態、里別變更時，重建 OG 圖卡（一般 build 不需要 Pillow）：

```bash
python3 scripts/build_share_cards.py --font /path/to/NotoSansCJKtc-Regular.otf
```

字型為 Noto Sans CJK TC（SIL OFL 1.1）。字型檔不加入網站；產生器使用已安裝的字型。PNG 與 manifest 一併版控。CI 已加入搜尋索引重建、PNG 一致性檢查與 P0 瀏覽器測試。

## 驗收方式

- 按 ⌘K／Ctrl+K 搜尋「文德國小」，查看標示、結果與 Enter 開啟；手機由選單開啟搜尋。
- 在 Dashboard 點「已完成」應得到 3 筆；切到 2013 年應為鳳山車站整合專題。
- 點鳳山車站群組，切換專題，分享後重新開啟確認選取一致。
- 檢查首頁左圖右文、各分頁頁首與文章外框，以及全站服務條款入口。

## 已知限制

- Facebook／Canva 內嵌與 OSM 外部底圖可能受供應商或隱私設定限制；保留原始連結及地圖的列表替代入口。
- 篩選 URL 在靜態主機共用政績集合頁 OG；每個獨立專題有專屬縮圖，不宣稱每組 query 都有動態 OG。
- 社群平台抓圖與快取取決於平台實際抓取時間；SEO metadata 驗證不等於保證搜尋排名。
