# Product thesis · 鳳山公共資訊誌

讓市民從一個地點、一個生活議題或一項服務需求，找到可閱讀、可追溯、可分享的公開資訊。

Primary jobs: contact office; prepare legal consultation; find local project; read chronology and sources; browse public reports. Homepage is a reading/discovery desk, not a KPI dashboard or persuasion funnel.

IA: visible task routes on homepage, full directory navigation retained for familiar users; dedicated stable article URLs; geography/topic through current filters. Design: existing forest green/lime identity, warm paper reading surface, editorial serif headlines and restrained rules, asymmetrical feature/utility composition. Interaction: full-site local search immediately accessible, map/list choice, source/history anchors and cross-topic links. Data: existing reviewed records; home previews generated from stable IDs rather than duplicated prose. Content: retain original political copy in profile context, no stronger claims. Technical: static HTML + vanilla JS + Python, no new production dependency.

Selected 06, with 01/02/04 service-search-source mechanics and existing 07/09/10 exploration. Rejected immersive/AI concepts because no truthful geometry or additional service benefit. No case backend, personalized political message, inferred completion date, new publication approval or donation conversion experiment.
