# Information architecture

Home → [查地方建設 → achievements filters / map] [找公開資訊 → search / explore] [聯絡與法律諮詢 → service] [反映問題 → petition].

Discovery → public detail → reading anchors (重點 / 歷程 / 來源) → related topic / place. News and office releases remain separate. Historical policy, election, donation, profile, activities and gallery remain reachable with unchanged URLs. Existing full navigation remains a directory; homepage task routes supply hierarchy without breaking old shortcuts.

Mobile: search and four task links first; selected project text before imagery; map/list controls above results; service choices above legal rules. No forced location permission. Empty results show reset. With JS off, normal links and all public list records remain readable.
