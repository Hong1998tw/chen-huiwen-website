# Design system

Forest ink #163e32 / green #075548, lime #dcf279, paper #f7f6ef, white panels, text #233a31, muted #506259, line #ced6cc. No new brand or decorative generated assets. Noto Serif TC/system serif for editorial titles; existing system sans for controls/body. No remote font dependency. Headline clamp 2.2–4.8rem; prose 1–1.125rem, line-height 1.85, max 48rem.

Grid 1200px max, 32px desktop / 16px mobile gutters; 8px rhythm, 24/40/64px section separation. Borders and baseline rules distinguish sections; 0–8px radius for editorial surfaces, existing icon/brand retained. Status always literal text. Inputs min 44px; focus 3px green with offset. Original photos preserve aspect and caption; portrait is a profile element, not purported project evidence.

Desktop lead 1.35:1 search/editorial pair with utility rail. Mobile at 780px collapses to single-column reading. Map keeps existing Leaflet assets; list alternative explicit. Timeline keeps actual date strings. Sources underlined, not tiny badges. Motion only short color/focus transitions; reduced-motion suppresses transforms. Print omits menu/third-party embeds, retains source URLs and text.
